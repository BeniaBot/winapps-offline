# Permissions given to this project

Where a maker's own licence does not permit redistribution, nothing goes on the site or on a
disc until they say it may. This file records what was asked, who answered, and what they said.

It is kept for two reasons. The first is that a promise remembered is not a promise anyone can
check. The second is practical: if a question ever arises, the answer is written down with a date
rather than reconstructed from memory.

---

## אוצריא (Otzaria) — permission granted

**Asked:** 2026-09-06, on the Otzaria community forum, by בנימין מחשבים.

> לפי הרישיון של אוצריא - מותר לי לשים אותה בחנות שלי?
> …
> את התוכנה כולל המאגר. הרישיון אוסר בלי אישור

**Answered by:** י. פל., of the Otzaria project.

> אני חושב שהרישיון מתייחס לקוד (או לשימוש בספרים) - לא לתוכנה הבנויה…
> בכל מקרה - מאשר לך להרבות את הפצתה, והרישיון נועד להגביל אנשים וחברות ידועים…

**What this covers:** distributing the built program together with its book database, through
this project.

**Why it was needed:** the repository's LICENSE is a "Personal Use License, Version 1.0", whose
section 3 forbids copying, publishing, redistributing, lending or transferring the software to
any other person or entity, and whose section 2 applies that whether the use is commercial or
not. The tag the store carries already ships that text, so the grandfather clause for earlier
releases does not reach it. Without this permission the program could not be listed.
