# חנות אפליקציות אופליין ל-Windows

**האתר: https://beniabot.github.io/winapps-offline/**

להתקין ולעדכן את האפליקציות של Windows במחשב שאין בו חיבור לאינטרנט —
בלי הרשאות מנהל.

## הבעיה

חלק מהאפליקציות של Windows מגיעות כקיצור דרך בלבד. בפתיחה הראשונה הן
כותבות "זקוק לעדכון" ומנסות למשוך את עצמן מהחנות. במחשב מנותק זה נכשל,
ואין דרך רשמית לעקוף את זה: מיקרוסופט סגרה ב-2023 את
`Microsoft Store for Business` עם הרישוי האופליין.

## הפתרון

מורידים כלי קטן, מריצים אותו על מחשב **שיש** בו אינטרנט, ובוחרים
אפליקציות. הכלי מוריד אותן מהשרתים של מיקרוסופט — עם כל ספריות המערכת
שהן דורשות — ואורז תיקייה אחת עם מתקין גרפי. מעתיקים את התיקייה לדיסק
און קי, ומריצים אותה במחשב המנותק.

[⬇ הורדת הכלי](https://github.com/BeniaBot/winapps-offline/releases/latest/download/winapps-packer.exe)
· Windows 10/11 · ~1.7MB

## מה יש בקטלוג

37 אפליקציות, מחולקות לשתיים:

- **עובדות בלי אינטרנט (21)** — מחשבון, כלי החיתוך, תמונות, רשמקול,
  פתקים דביקים, סוליטר, Terminal, OneNote ועוד.
- **דורשות אינטרנט כדי לתפקד (16)** — מפות, דואר, Office, Xbox ועוד.
  הן מתקינות מצוין בלי רשת, אבל התוכן שלהן חי ברשת. שימושיות למחשב
  שיתחבר בהמשך, או לעדכון גרסה אחרי ניקוי מערכת.

הרשימה המלאה, עם גרסאות וגדלים, מוצגת באתר.

## גם עדכון, לא רק התקנה

אפשר להתקין גרסה חדשה מעל קיימת בלי להסיר ובלי לאבד נתונים. המתקין
בודק מה מותקן ואומר מראש מה יקרה: "עדכון זמין", "כבר מותקנת", או
"דורש Windows חדש יותר".

## לטכנאים

בכלי יש **"סמן הכל"** — לוחצים פעם אחת ומקבלים את כל החנות בתיקייה
אחת, עם מתקין משולב שמציג רשימת סימון של מה חסר ומה מיושן.

כ-4.7GB ל-Windows 10, כ-6.2GB ל-Windows 11. מעבירים בכונן NTFS או
exFAT — קובץ מעל 4GB לא נכנס ל-FAT32.

## הבהרות

- החבילות יורדות מהשרתים של מיקרוסופט, חתומות דיגיטלית על ידה ואינן
  משונות. **המאגר הזה אינו מאחסן אף קובץ של מיקרוסופט** — הכלי מוריד
  אותם ישירות מהמקור, אצל המשתמש.
- הכלי אינו חתום דיגיטלית. ייתכן ש-SmartScreen יציג אזהרה בהפעלה
  הראשונה: "מידע נוסף" ← "הפעל בכל זאת".
- הפרויקט אינו קשור למיקרוסופט ואינו נתמך על ידה.

## הפעלת האריזה בדפדפן (ממסר)

הדפדפן חסום מלגשת ישירות לשרתי מיקרוסופט (אין שם CORS). כדי שהאתר
יארוז בעצמו, פורסים ממסר זעיר — `worker/relay.js` — ב-Cloudflare Workers
(חינם, 5 דקות, בלי אחסון):

1. חשבון Cloudflare ← Workers & Pages ← Create Worker.
2. מדביקים את תוכן `worker/relay.js`, לוחצים Deploy.
3. את הכתובת שמתקבלת שמים ב-`index.html` במשתנה `RELAY_URL`.

בלי ממסר האתר עובד במסלול קובץ-הבחירה + הכלי.
